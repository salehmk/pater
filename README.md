# Pater

مستودع يحتوي على جداول أوقات الصلاة اليومية لمناطق ومدن مختلفة، بصيغة JSON سهلة القراءة والاستخدام.

## ما هذا المشروع؟

هذا المشروع يقدّم بيانات يومية لأوقات الصلاة (الفجر، الشروق، الظهر، العصر، المغرب، العشاء) لمدن ومناطق متعددة، مع كل يوم في ملف مستقل. يتم تنظيم البيانات على شكل JSON بحيث يمكن استخدامها بسهولة في تطبيقات الويب أو تطبيقات الهاتف أو أي مشروع آخر يحتاج إلى أوقات الصلاة.

## هيكل المشروع

يتكوّن المشروع من ملفات JSON، كل ملف يمثل منطقة أو مدينة معينة، مثل:

- `Al_Azraq.json`
- `Amman_Balqa_Zarqa_Madaba.json`
- `Irbid.json`
- `Aqaba.json`
- `Maan.json`
- `Shobak_Petra.json`
- `Um_Qutain.json`

وهكذا... كل ملف يضم قائمة يومية بتنسيق موحّد.

## مثال على هيكل البيانات

```json
[
  {
    "Date": "01/01/2026",
    "Fajr": "06:06",
    "Sunrise": "07:29",
    "Dhuhr": "12:36",
    "Asr": "03:22",
    "Maghrib": "05:44",
    "Isha": "07:07"
  }
]
```

## الحقول الموجودة في كل سجل

- `Date`: التاريخ
- `Fajr`: وقت الفجر
- `Sunrise`: وقت الشروق
- `Dhuhr`: وقت الظهر
- `Asr`: وقت العصر
- `Maghrib`: وقت المغرب
- `Isha`: وقت العشاء

## كيفية الاستخدام

يمكنك فتح أي ملف JSON والقراءة منه كقائمة من الكائنات، ثم استخراج الوقت المناسب لليوم المطلوب.

مثال بسيط باستخدام JavaScript:

```javascript
const data = require('./Amman_Balqa_Zarqa_Madaba.json');
const today = data.find(item => item.Date === '01/01/2026');
console.log(today.Fajr);
```

## الهدف

الهدف من هذا المشروع هو توفير بيانات دقيقة وسهلة الاستخدام لأوقات الصلاة لأماكن مختلفة، مع إمكانية دمجها في تطبيقات أو مواقع أو أدوات داخلية.
